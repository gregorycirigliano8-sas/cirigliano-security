## About the sample report

The sample report is illustrative. It is **not** a client deliverable.

- Every number in it comes from real test runs, but only against local test systems on loopback: a reference implementation and a mock service that was deliberately made vulnerable.
- No client, customer, or third-party system was tested.
- It contains no client data, credentials, or confidential information.

Its purpose is to show the structure, evidence, and level of detail you get from a real engagement.

## How engagements work

All testing is done only with signed written authorization and an agreed scope, and only against staging environments, never production.
