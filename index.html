Who it's for

Startups (typically seed to Series B) shipping LLM agents that can take real-world actions—especially teams facing enterprise security questionnaires or SOC 2 pressure.

Strong fit

  • Agents that call tools / APIs / browsers
  • Agents that read customer data (CRM, tickets, docs)
  • Agents that hold API keys or wallet credentials
  • Agents that move money, credits, or entitlements
  • Infra / SRE agents that can change production systems

Not a fit (yet)

  • Marketing chatbots with no tools or data access
  • Pure model demos without credentials or actions
  • Production-only testing without a staging path
  • Engagements without written authorization

What's tested

Two complementary halves—model behavior and credential lifecycle—so you don't get a PDF of prompt tricks with no revoke story (or the reverse).

Model-facing · promptfoo red-team

Will the model abuse tools or leak?

  • Prompt injection & jailbreak resistance
  • Tool / function abuse (unapproved HIGH actions)
  • Data exfiltration attempts
  • Secret & key leakage in responses
Credential lifecycle · agent test harness

Does revoke actually stop the agent?

  • Captured-credential revoke latency
  • Fail-closed when auth is unreachable
  • Replay of revoked credentials / old requests
  • HIGH-action approval gates (missing / stale / mismatched)
  • Rate / budget limits
  • Tamper-evident evidence ledger

FAQ

Do you test production?

No by default. Reviews run against staging (or an explicitly authorized test environment). Production requires separate written approval.

Is this the same as a smart-contract audit or classic web pentest?

No. This is scoped to LLM agents: model abuse of tools/data and the credential/revoke story when an agent or key is captured.

What do you need from us to start?

A signed scope, staging access or a mock endpoint, a list of tools/risk tags, and a test credential via secure channel (never committed to tickets or chat logs).

Will you invent findings with AI?

Automated tools help generate cases; every finding is validated against your system with evidence in the ledger before it goes in the report.

Can this turn into ongoing help?

Yes. Fractional security engineering is available from $4,000/month after (or instead of) a fixed review.

Ready for a scoped review?

Two November-style slots work best when you already have a staging agent and an enterprise deadline. Email with a one-paragraph description of your agent and tools.
